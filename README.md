# My Anime Book — agent-driven manuscript

Этот репозиторий организован как рабочая среда для написания книги через pull request и цепочку специализированных агентов.

## Как устроена работа

1. Автор формулирует новую задачу в `tasks/current.md`.
2. Пишущий агент читает инструкции из `agents/` и обновляет рукопись.
3. Редакторские агенты проверяют стиль, драматургию, непротиворечивость и качество текста.
4. Все изменения остаются в одной ветке и обсуждаются в pull request.
5. После одобрения PR изменения попадают в основную версию книги.

## Обязательный порядок чтения для агента

1. `agents/AGENT_ENTRYPOINT.md`
2. `agents/WRITING_RULES.md`
3. `agents/STYLE_GUIDE.md`
4. `canon/BOOK_BIBLE.md`
5. `outline/CHAPTER_PLAN.md`
6. `tasks/current.md`
7. релевантные файлы из `manuscript/`

## Основные каталоги

- `agents/` — инструкции, роли и порядок работы агентов.
- `tasks/` — текущее задание и журнал завершённых итераций.
- `canon/` — канон мира, персонажей и терминов.
- `outline/` — структура сюжета и планы глав.
- `manuscript/` — текст книги.
- `reviews/` — результаты редакторских проверок.

Подробнее см. `agents/PIPELINE.md`.
